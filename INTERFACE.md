# Routing-MDP Environment Interface (v2) — for prompts, parser, and evaluator

Module: `resource_mdp.py` (stdlib only, Python 3.8+). Schema version **2.0**.
This is the interface to freeze before model runs. Everything below is
generated by `make_pair` + `paired_evidence` and serialized by `pair_to_json`;
the two example files (`example_deterministic_silent_break.json`,
`example_stochastic_silent_break.json`) are instances of exactly this schema
(seed 7, condition `silent_break`, k=5).

## 1. Handoff table → implementation

| Handoff request | Where it lives |
| --- | --- |
| Paired worlds, exact diff, old/new p | `make_pair(seed, condition, ...)` → `PairedInstance(m0, m1, change, ...)`; M0 is never mutated |
| Deterministic + stochastic, same interface | `deterministic=True` sets `p_range=(1,1)` through the same code path; **topology is identical per seed across modes** (rng draw count is unchanged) |
| Five conditions | `condition ∈ {no_change, irrelevant, degradation, silent_break, hard_removal}` |
| Balanced per-(s,a) pre/post evidence, matched events | `collect_balanced` / `paired_evidence(inst, k, evidence_seed)` — ≥ k attempts per listed pair in each world, random starts, verifiable `counts_*` |
| Oracle metadata | `PairedInstance.oracle` — pre/post solvability, optimal route/cost, tie info, alternative proper route |
| Reproducibility | all rngs seeded with explicit strings (stable across processes); eligible break drawn at random (`change_seed` redraws on the same graph); action labels are opaque |
| Scoring seam | `score_route`, `route_from_actions`, `broken_link_usage`, `regret` are environment primitives; evaluator computes headline metrics on top |

## 2. Core API (field names to code against)

```python
inst = make_pair(seed, condition, deterministic=False, n_nodes=8,
                 extra_edges=6, p_range=(0.6, 0.95), obfuscate=False,
                 degradation_factor=0.5, change_seed=None)
# -> PairedInstance:
#    .condition .deterministic .start
#    .m0 .m1          RoutingMDP (pre / post); .m1 is .m0 under no_change
#    .labels          {(u, v): "aK"}  opaque, assigned on M0, stable
#    .change          exact diff (see §4)
#    .oracle          metadata bundle (see §5)
#    .seeds .params   full provenance

ev = paired_evidence(inst, k=5, evidence_seed=0, horizon=60)
# -> dict with pre/post renderings + counts (see §6)

record = pair_to_json(inst, ev)   # the full JSON instance (see §3)
```

`RoutingMDP` internals the evaluator may touch: `.nodes`, `.goal`,
`.p[(u, v)]`, `.broken` (v1 compat), `.changes` (full intervention log),
`.out_edges(u)`, `.optimal()` → `(dist, best)`, `.optimal_route(start)` →
`(path, cost)`, `.plan_cost(path)`, `.set_link_prob(u, v, new_p, mode)`,
`.break_link(u, v, mode)`, `.copy()`.

Rollout side: `Attempt(t, node, chosen, success, next_node)`;
`rollout(mdp, start, policy, rng, horizon)`; policies `optimal_policy`,
`explore_policy` (v1 ε-greedy, kept as a comparison collector),
`fixed_policy` (stale-planner baseline; falls back to the first listed link
if its frozen hop was hard-removed).

## 3. JSON instance — top level

| Field | Content |
| --- | --- |
| `schema_version` | "2.0" |
| `condition`, `deterministic` | condition name; mode flag |
| `seeds`, `params` | full provenance: `graph_seed`, `change_seed` (string), `label_seed`; generator params |
| `nodes`, `goal`, `start` | node names (A–H, or 3-letter strings when `obfuscate`); start = farthest solvable node |
| `legal_actions_pre/post` | `{node: ["a1", "a2", ...]}` — the model-visible action menus (they differ only under `hard_removal`) |
| `world_pre/post` | `{"edges": [{"from", "to", "p", "action"}, ...]}` — ground-truth graphs |
| `change` | exact diff (§4) |
| `oracle` | metadata bundle (§5) |
| `evidence` | balanced observations in five formats + counts (§6) |
| `model_visible` | `nodes, start, goal, legal_actions_*, evidence` — the only fields allowed into prompts |
| `evaluator_only` | everything else (`world_*`, `change`, `oracle`, `seeds`, `params`, `counts_*`) |

## 4. `change` — the exact diff (localization ground truth)

```json
{"edge": {"from": "C", "to": "D"}, "action": "a2",
 "old_p": 0.73, "new_p": 0.0, "mode": "silent",
 "on_optimal_route": true, "route_position": 1}
```

`edge` is `null` and `mode` is `"none"` under `no_change`. `new_p` is `null`
under `hard_removal`. `route_position` is the 0-based index of the edge in
the PRE-change optimal route (`null` if off-route). `action` is the opaque
label of the changed pair — the localization answer in the model's own
vocabulary. Condition semantics:

| condition | target | effect | guarantees |
| --- | --- | --- | --- |
| `no_change` | — | M1 = M0 | false-positive control |
| `irrelevant` | random OFF-route edge | p × `degradation_factor` | optimal route provably unchanged (off-route costs can only rise) |
| `degradation` | random ON-route edge | p × `degradation_factor` (min 0.05) | still solvable; route may or may not change (`oracle.route_changed`) |
| `silent_break` | random eligible ON-route edge | p → 0, still listed | goal stays reachable → forces replanning, not impossibility |
| `hard_removal` | same eligible set | edge leaves the action set | detection trivial by menu diff — the easier control |

Eligibility = `breakable_route_links` (break preserves reachability from
`start`). If a seed admits none, `make_pair` raises `ValueError` — 80/80
tested (seed, mode) combinations were eligible, so in practice pick any seed.

## 5. `oracle` — evaluator ground truth

Per world (`pre`, `post`): `solvable`, `optimal_route` (node list),
`optimal_actions` (same route as opaque labels), `optimal_cost` (exact
expected attempts), `route_unique` + `tie_nodes_on_route` (nodes on the
route with >1 optimal hop — always check this before treating "wrong route"
as an error, especially in deterministic mode where ties are common),
`alternative_route` / `alternative_actions` / `alternative_cost` (best
proper route avoiding ≥1 optimal edge). Top level: `start`, `goal`,
`route_changed`, `cost_delta`.

## 6. `evidence` — what the model sees

`pre` and `post` each carry the SAME event set in five renderings:

| Key | Rendering | Use |
| --- | --- | --- |
| `F1_log` | `t=1 \| at C \| send a2 \| DROP, stay C` (episode-separated) | ordered trajectories |
| `F2_ordered` | `(C, a2, C)` in trajectory order | ordered atomic triples |
| `F2_shuffled` | the same triples, pooled + shuffled | **shuffled atomic facts** condition |
| `F3_stats` | `C a2: 33 attempts, 0 delivered (0.00)` | aggregated stats — explicit-model control |
| `F4_narrative` | "At C, the packet was sent via action a2, but the link dropped it…" | natural-language episodes |

Plus `counts_pre/post` (`{"C->D": {"attempts": 33, "delivered": 0}}` —
evaluator-side, keyed by true edges), `min_attempts_pre/post` (balance
proof, ≥ k), `episodes_pre/post`, `k_per_pair`, `evidence_seed`.
Collection: episodic rollouts, random starts, least-tried action rule,
until every listed pair has ≥ k attempts — so the silently broken pair
gets ≥ k all-drop observations post-change, which is the detection signal.

## 7. Parser contract (proposal — freeze together)

Model answers, per probe:

1. **Detection** — `{"changed": true|false}` → compare against
   `condition != "no_change"` (note: `irrelevant` counts as changed; it
   controls localization and plan-preservation, not detection).
2. **Localization** — `{"node": "C", "action": "a2"}` → compare against
   `change.edge.from` + `change.action`. (Node+label uniquely identifies
   the edge without asking the model to name hidden destinations.)
3. **Preservation** — T1/T3 probes on UNCHANGED pairs pre vs post;
   ground truth from `world_*` / `counts_*`.
4. **Adaptation** — a route, either as nodes `["E","A","D","B","F"]` or as
   actions `["a2","a1","a2","a2"]`. Pipeline:
   `path = route_from_actions(start, actions, labels)` (if labels) →
   `score_route(m1, path, start)` →
   `{"valid", "expected_cost", "optimal_cost", "regret"}`.
   A plan through a hard-removed edge translates but scores invalid —
   intended. Behavioral variant: `broken_link_usage(attempts, u, v)`
   (returns `None` if the agent never visits `u`; the evaluator decides
   how to treat avoidance).

Endpoints verified in tests: stale planner usage = 1.00; adapted = 0.00 or
node avoided; optimal plan regret = 0.

## 8. Invariants the tests enforce (`test_resource_mdp.py`)

Same seed → bit-identical graphs, diffs, labels, and evidence strings.
Deterministic mode: identical topology per seed, all p = 1, cost = hops.
M0 never mutated. Irrelevant change preserves the optimal route. Break
randomized over the eligible set only. Balance ≥ k pre and post; shuffled
facts are an exact permutation of ordered facts. Labels per-node unique,
stable across the pair (no renumbering leak after removal), purely `aK`.
All conditions keep the post-world solvable from `start`. Full record
JSON-round-trips.

Run: `python3 test_resource_mdp.py` (no dependencies).
