# Code of conduct

This is a small research repository. The rules that matter here are about
handling evidence and each other's work, so those are what this says.

## Standards

**Represent evidence accurately.** State what was measured, on what n, by
which script. If a number came from someone else's document rather than from
code in this tree, cite it and mark it provisional until the definition
behind it is written down.

**Do not overstate.** A result that holds on one model, one seed, or one
condition is reported that way. A check that has only ever passed has been
run, not tested.

**Say what is not done.** The README has a section for it. Gaps stated plainly
are worth more than gaps a reader discovers.

**Credit accurately.** Attribution follows contribution. Authorship and author
order are discussed openly, not assumed.

**Touch other people's work carefully.** Changing someone's module without
telling them is how two implementations of the same thing get built in
parallel, which has already happened here twice. Open a pull request and
explain the reasoning; let the owner decide.

**Disagree about the work, not the person.** Reviews are about code, methods
and claims. A correction is not a criticism of whoever wrote it, and finding a
defect in your own work is worth as much as finding one in someone else's.

## Not acceptable

Harassment, personal attacks, or discriminatory language. Publishing others'
private information. Presenting someone else's work as your own, or removing
their attribution. Reporting results that the artifacts do not support.

## Scope

Applies in this repository, its issues and pull requests, and in team channels
where the project is discussed.

## Enforcement

Raise concerns with Efe Bektes, bektes23@itu.edu.tr, or with the project
supervisors. Reports are handled privately. Consequences range from a request
to change behaviour up to removal of repository access.

Adapted in spirit from the Contributor Covenant, rewritten for a four-person
research project rather than a large open-source community.
